如何生成 Token（Fine-grained，约 1 分钟）

  1. 打开 github.com/settings/personal-access-tokens/new
  2. Repository access 选择 Only select repositories，勾选博客仓库
  3. Permissions → Repository permissions → Contents 设为 Read and write
  4. 生成后复制 github_pat_ 开头的 Token，粘贴到上方
