## 写在前面

本站的文章就是 `posts/` 目录下的 **Markdown（.md）文件**。在后台「文章管理」里点「+ 新建文章」或「导入 MD」都可以写作；写完点「保存并发布」，文件会通过 GitHub API 提交到仓库，首页 1 分钟内可见。

> 本篇文章当前是「待发布」状态：**待发布的文章不会显示在首页**，只在后台「文章管理」中可见。在列表中点「发布」才会出现在首页；已发布的文章也可以点「撤回」变回待发布。

## 一、文章头部信息（Front Matter）

每篇文章开头用三行 `---` 包裹的 YAML 区记录元信息，格式如下：

```markdown
---
title: "文章标题"
date: 2026-10-01
tags: ["教程", "技术"]
summary: "一句话摘要，会显示在首页卡片上"
draft: false
---

正文从这里开始……
```

各字段说明：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `title` | 必填 | 文章标题，显示在首页和文章页 |
| `date` | 必填 | 日期，格式 `2026-10-01`，用于首页排序 |
| `tags` | 可选 | 标签，用英文逗号分隔，多个写成 `["A", "B"]` |
| `summary` | 可选 | 摘要，留空则自动截取正文开头 |
| `draft` | 可选 | `true` 待发布 / `false`（或省略）已发布 |

导入的 MD 文件如果没有 Front Matter，会自动从文件名和正文推断标题、日期，并**默认设为待发布**。

## 二、常用 Markdown 语法

### 标题与段落

```markdown
# 一级标题
## 二级标题
### 三级标题

普通段落直接写文字，段与段之间空一行。
```

### 列表

```markdown
- 无序列表项一
- 无序列表项二
  - 嵌套项（前面多两个空格）

1. 有序列表项一
2. 有序列表项二
```

### 引用与代码

```markdown
> 这是一段引用文字，适合放名言或重点提示。

行内代码：用 `printf("hello")` 这样的格式。

```c
/* 代码块示例 */
#include <stdio.h>
int main(void) {
    printf("hello, Jiumo_Page!\r\n");
    return 0;
}
```
```

> 提示：代码块用三个反引号包裹，开头可以写语言名（如 `c`、`python`、`js`）实现高亮。

### 加粗与斜体

```markdown
**加粗文字**，*斜体文字*，***加粗斜体***，~~删除线~~。
```

### 表格

```markdown
| 功能 | 入口 | 说明 |
| --- | --- | --- |
| 看文章 | 首页 | 自动按日期倒序排列 |
| 写文章 | /admin | 支持实时预览 |
| 删文章 | /admin | 删除后立即提交仓库 |
```

### 链接与图片

```markdown
链接：[GitHub 官网](https://github.com)

图片：图片放在 `posts/images/` 目录后引用
![描述](images/图片名.png)
```

也可以直接粘贴图床链接：

```markdown
![描述](https://example.com/xxx.png)
```

## 三、发布 / 待发布流程

1. **新建文章**：默认直接发布（首页可见）；
2. **导入 MD**：导入后一律为**待发布**状态，出现在「文章管理」列表，等你确认、修改后再发布；
3. **发布**：待发布文章点「发布」，立即提交到仓库，首页 1 分钟内可见；
4. **撤回**：已发布文章点「撤回」，变回待发布，首页立即不再显示；
5. **编辑**：点「编辑」修改标题、日期、标签、摘要和正文，保存后保持原有发布状态。

## 四、小技巧

- 文件名建议：`2026-10-01-文章标题.md`，日期前缀用于排序；
- 摘要太长会截断，尽量一句话；
- 文章里想放分割线，用三个短横线 `---`；
- 想换行但不分段，句末加两个空格再回车。
